# Monitoramento de contratos — MGC

Protótipo de validação de um painel de monitoramento dos contratos de destinação do MGC (Módulo Gestão de Contratos do SPUnet), por superintendência: obrigações com vencimento calculado, ciclos de cobrança anuais, tarefas da equipe e notificação ao outorgado.

**Dados fictícios.** Nada é enviado de fato; o que se faz no protótipo fica só no navegador de quem usa. A barra escura do topo troca a visão (chefe ou servidor) e recomeça os dados.

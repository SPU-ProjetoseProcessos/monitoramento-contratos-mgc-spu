# Monitoramento de contratos — MGC

Protótipo de validação de um painel de monitoramento dos contratos de destinação do MGC (Módulo Gestão de Contratos do SPUnet), por superintendência: obrigações com vencimento calculado, datas de cobrança que se repetem todo ano e tarefas da equipe. A ferramenta não se comunica com o outorgado: a cobrança é feita por fora e aqui só se registra.

**Dados fictícios.** O que se faz no protótipo fica só no navegador de quem usa. A barra escura do topo troca a visão (chefe ou servidor) e recomeça os dados.
